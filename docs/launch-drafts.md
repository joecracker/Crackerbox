## Dyad community post

**Title:** Crackerbox: a Dyad remix where your AI helpers are a crew, not a chat box

Hey all. I'm not a coder. I'm an ideas guy who builds with AI, and I remixed Dyad into something that fits how I like to work. I'm sharing it in case it fits you too.

What's different:

- **Entities.** Your AI helpers are avatar circles in the left bar. Each has its own room (a project), its own memory and its own personality. Click one and you're talking to it.
- **Jobs as tabs.** The tabs along the top are jobs, each tagged with whoever is doing it.
- **They pass notes.** Entities can leave each other notes and share a few common notes, so the one writing copy can learn what the one writing code decided.
- **Phone and schedule.** Give an entity its own Telegram bot and message it from your phone. Set daily check-ins that run quietly in the background.
- **Plugins.** The usual plugin (MCP) tools work.
- **Bring your own keys.** Nothing is locked to one provider.

Straight talk: I built this for myself, not for anybody else. I'm not selling anything, not trying to show off and not trying to talk anyone into using it. I'm just putting it out there in case somebody can get some use out of it. It's built around my taste, so feedback is welcome, but an idea only goes in if it fits what Crackerbox is for.

Screenshots and a one-page guide to how the crew works are in the repo. Repo: https://github.com/joecracker/Crackerbox
